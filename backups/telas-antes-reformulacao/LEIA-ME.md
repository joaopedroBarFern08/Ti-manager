# Backup das telas antes da reformulação

Esta pasta guarda as versões anteriores das três telas e da folha de estilos compartilhada.

Para restaurar o visual anterior, copie os arquivos abaixo para os caminhos originais do projeto, substituindo as versões atuais:

- `atendimentos.html` → `templates/atendimentos.html`
- `maquinas.html` → `templates/maquinas.html`
- `estoque.html` → `templates/estoque.html`
- `style.css` → `static/css/style.css`

As alterações de dados nas rotas e os filtros JavaScript não fazem parte deste backup visual.
